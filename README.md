# Cesta no Ninho - MVP Web

Website funcional e elegante baseado no serviço da Cesta no Ninho, desenvolvido com React, Vite e Tailwind CSS. Inclui personalização interativa de itens de cestas com cálculo dinâmico e integração direta para pedidos via WhatsApp.

## Como Executar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
3. Abra http://localhost:5173 no seu navegador.
